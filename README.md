# Instance Page v2

*The green-era Stux.Cloud instance page, preserved.*

An archived, pinned snapshot of [StuxCloud/instancepage](https://github.com/StuxCloud/instancepage), frozen at its `faa842e` commit (`v1.3.2`): the last state of the page before Stux.Cloud moved from its two-tone green brand to the single teal `#07878e`. This repository exists so the green design stays available and independently versioned as `v2`, separate from the live template's ongoing development.

Live at [instancepage-v2.stux.cloud](https://instancepage-v2.stux.cloud/). Its logo, icon and favicon are pinned to the archived green assets under `https://global.media.stux.cloud/v2/`.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/StuxCloud/instancepage-v2.git
   ```

2. Run it locally:

   ```bash
   ./dev-server.sh        # or dev-server.bat on Windows
   ```

   Then open the printed URL. You can also open `index.html` directly in your browser.

## Scope

This repository is an archive, not the actively developed template. Contributions are limited to fixes that keep this exact design working (broken links, encoding issues, browser compatibility). For new features or a redesign, see the live [instancepage](https://github.com/StuxCloud/instancepage) repository instead.
